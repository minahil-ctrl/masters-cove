# Masters Cove

A planner for masters applications. Live at https://minahil-ctrl.github.io/masters-cove/

## Modules

- **Dashboard**: milestone countdown, readiness strip, KPIs, search across everything, a 30-day deadline radar, tasks coming up, list balance (reach / target / likely) and budget.
- **Planner**: tasks with priority, category and linked program; readiness gates; phase plan; export every date to your calendar (.ics).
- **Programs**: requirements, costs, admissions contact, portal links, tier and fit score per program. Card, table, map (field × country) and deadline timeline views; side-by-side comparison; CSV export.
- **Applications**: pipeline board and table from shortlist to decision, with a 10-step portal checklist per program.
- **Documents**: checklist with expiry dates, copies, issuing office and links to your own copies; test scores; recommenders; contacts directory; official links (HEC, MOFA, IELTS, EducationUSA, DAAD, uni-assist and more).
- **Writing**: SOPs, essays and CV with word counts against limits.
- **Funding**: funding routes and a matrix of tuition, living costs, expected funding and the gap.
- **Scoring**: weighted dimensions and presets that drive each program's fit score.
- **Ambition**: Harada method goal sheet (Open Window 64), daily routines and diary.
- **Profile**: the academic and work facts requirements are checked against.

## Profiles and privacy

Each person makes their own profile the first time they open the page. Everything is saved only in that browser (`localStorage`). Nothing is sent to a server, so nobody else can see your plan, and it does not sync between devices.

Use **Profile → Download backup** now and then. To move your plan to another device, download a backup and use **Profile → Restore from backup** there.

## Run it

A single `index.html` with no build step. Open it in a browser, or host it on GitHub Pages.
